# Tisdale's Southern BBQ 🍖🔥

> **"Mouth-Watering, Tongue-Twisting BBQ — Low & Slow Real Smoke"**  
> Serving Fayetteville, Sanford, Dunn, and surrounding North Carolina communities.  
> Owned & operated by Pitmaster Donald Tisdale (Phone: 910-709-2900).

A modern, mobile-first web app and on-the-fly "Pocket Pitmaster" dashboard designed to replace their slow, broken Wix template with an ultra-fast, responsive experience that Donald can update from his phone in 10 seconds while standing at the smoker.

---

## 🌟 Key Features

### 1. Customer Mobile Experience (<0.5s Load Time)
- **Live Location Card:** Real-time pin of where the food trailer is parked today, operating hours, and 1-tap Google Maps directions.
- **Full TV Screen Main Menu:** Complete categorized listing of Dinners & Plates, Sandwiches & Handhelds, Bulk Meats by the Pound & Slab, Homestyle 8oz Sides, and Desserts & Drinks.
- **Specials in Multiple Spots:**
  - Sticky Top Marquee ticker with urgent kitchen announcements.
  - Interactive "Window Whiteboard" & "A-Frame Chalkboard" showcase featuring multi-meat combos, fried pork chops, and fresh catfish/shrimp catches.
  - Embedded badges and callouts across all menu categories.
  - Floating 1-tap "Today's Specials" drawer.
- **"My Plate" Order Tray:** Instant subtotal & NC sales tax calculation, with 1-tap *"Call Trailer to Place Order"* (`tel:9107092900`) and formatted text message ordering.
- **Working Catering Intake:** Replaces Wix's broken placeholder copy with an active event inquiry form.

### 2. Donald's 10-Second Pitmaster Quick-Admin
- **1-Tap Fryer Cutoff Switch:** Toggle *"Grease is Hot"* vs *"Grease is Off"*. Toggling off immediately badges all fried items as unavailable (enforcing the 30-min closing rule) while keeping wood-smoked meats active.
- **1-Tap 86 / Sold Out Buttons:** Instantly mark brisket, ribs, or turkey legs sold out from an iPhone without touching complex software.
- **1-Tap Location Presets:** Switch today's spot between Stop Button, North View Lanes, Static Line Brewing, Downtown Dunn, or custom venues in seconds.
- **Instant Local Sync:** Saves directly in browser storage across sessions.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation & Run

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
